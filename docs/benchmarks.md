# Benchmarks: web sizes

Generated by `tools/measure_sizes.py --write` from `benchmarks.json`, the baseline CI holds HeliX to (`--check`, in `helix.py test`: a rung more than 1% and 1 KB larger, gzipped, fails). Every rung is a release browser build as a game makes it (`-lib helix`, `-dce full`, the analyzer), its JavaScript unminified, as Haxe alone writes it; sizes in KB.

Measured from HeliX d78205a 2026-10-25 with Haxe 4.3.7.

## The feature cost ladder

Programs that each add one thing to the one before (`tests/sizes/`): what a feature costs on its own is its row's increment, gzip; brotli in brackets.

|---|---|---:|---:|---:|
| 1-window | a window cleared, nothing drawn | 116.6 | 26.5 (22.7) |  |
| 2-shapes | + the stage showing a rectangle | 265.3 | 80.5 (71.5) | +54.0 |
| 3-text | + text in the built-in font (the starter) | 265.4 | 80.6 (71.5) | +0.0 |
| 4-sprites | + a texture loaded and drawn | 315.8 | 91.6 (80.6) | +11.1 |

| 6-3d | + a 3D view of a lit cube | 512.9 | 128.9 (108.9) | +35.0 |
